# Разлом — Ночь мутантов

Браузерный эпизод в духе SEGA / Comix Zone: три панели комикса, драки с мутантами и прыжки между картинками с захватом рамки рукой.

Играть: https://rJIa3a.github.io/razlom/

На компьютере: Enter — начать; A/D или стрелки — движение; X/J — удар; Пробел — прыжок; P — пауза; R — заново.

На телефоне: коснитесь экрана, затем используйте кнопки внизу. Для удобства поверните телефон горизонтально. После победы над врагами подойдите к правой рамке и нажмите кнопку прыжка.

Разбивайте бочки ради лечения. После третьей панели прыжок у правой рамки завершает выпуск. Звук переключается кнопкой справа сверху.

Статическая игра на HTML/JavaScript/WebGL2. Серверная часть и регистрация для игроков не нужны. Первый выпуск: три боевые сцены и один тип мутантов.
